# Placement Preparation (12-week sprint)

Day-wise notes for campus placement preparation, aimed at System Engineer, Cloud Support, Infrastructure and Junior DevOps roles (with IT/technology consulting as a fallback).

**Sprint:** 2026-11-24 to about 2027-02-15 (12 weeks).
**Four tracks, every day:** English, Aptitude, DSA (Python), and DevOps with real projects (Linux first).

This work lives on the `devops` branch.

## Repository layout

| Path | What it is |
|---|---|
| `diagnostic-test.md` | 20-question baseline test, planned for the end of week 2 |
| `RESOURCES.md` | Optional extra reading, by track |
| `lessons/` | One file per subject per day: `<subject>-<day>-<topic>.md` |

## Day-wise index

| Day | Date | Aptitude | English | DSA (Python) | DevOps / Linux |
|---|---|---|---|---|---|
| 1 | 2026-11-24 | [Percentages](lessons/aptitude-01-percentages.md) | [Self-introduction and HR questions](lessons/english-01-self-introduction.md) | [Python basics](lessons/dsa-01-python-basics.md) | [Linux first steps](lessons/linux-01-first-steps.md) |

Each lesson file has the definitions, worked examples, the question types that repeat in campus tests, and practice questions. Solutions are added after the practice is attempted.

New days are added as new lesson files with their own commits.
