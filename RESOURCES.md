# Resource Guide: where to read and practice

**Optional.** I teach every topic fully in chat and in the [lessons](lessons/) folder, so you do not need anything below. Use this list only if you want a second explanation or extra practice.

**If you do use it:** pick **one main resource per topic** and finish it. Hopping between ten courses is the most common reason people stay stuck. Resources are in two levels: **Start here** (foundation and working level) and **Go deeper** (interview edge).
> I wrote this list from what I know about each resource, and I haven't opened every link today. Websites change. If a link is dead or a course is outdated, tell me and I'll find a replacement. Most things here are free. Paid items are marked **(paid)** and are optional.

## 1. Aptitude

| | Resource | Notes |
|---|---|---|
| **Start here** | [IndiaBix](https://www.indiabix.com) | Free topic-wise practice. Good for volume |
| | R.S. Aggarwal: *Quantitative Aptitude* and *A Modern Approach to Verbal & Non-Verbal Reasoning* **(paid book)** | The standard first book. Read concepts, then do examples |
| | [PrepInsta](https://prepinsta.com) | Company-wise pages (TCS, Infosys, Wipro, Accenture, Cognizant...) with sample questions and pattern notes |
| | [GeeksforGeeks aptitude section](https://www.geeksforgeeks.org) | Free explanations with shortcuts |
| **Go deeper** | Arun Sharma: quantitative aptitude books **(paid)** | Harder variants. Use only for topics where you stay below 85% |
| | Previous papers from TCS NQT, Infosys, Wipro, Accenture and Cognizant | Search each company's name + "previous year questions". Check the pattern is current |
| **Daily mental maths** | Tables to 20, squares to 30, cubes to 15, fraction-percent table (1/8 = 12.5%, 1/6 = 16.67%...) | 10 minutes a day makes everything faster |

**Method for going deep:** solve each important question **two ways** (normal method and shortcut). If you can't explain why a shortcut works, you don't own it yet.

## 9. Whole-path guides and interview banks

- [roadmap.sh/devops](https://roadmap.sh/devops): the complete map; tick off what you've done.
- *90 Days of DevOps* (Michael Cade, on GitHub): a daily-structured path to cross-check against ours.
- *DevOps Exercises* (bregman-arie, on GitHub): thousands of interview questions with answers, grouped by topic. Use from week 9.
- YouTube: freeCodeCamp (full courses) and TechWorld with Nana (Docker, Kubernetes, CI/CD explained clearly).
- Reading for interview talk: *The Phoenix Project* (a novel about DevOps) and *The DevOps Handbook*.
