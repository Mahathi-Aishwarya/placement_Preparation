# Aptitude Lesson 1: Percentages (full notes)

Percentages are the base of almost every other quant topic: profit and loss, discounts, interest, data interpretation, population. Master this and half of quant gets easier.

## 1. What is a percentage?

**Definition:** "Per cent" means "per hundred". A percentage is a fraction with denominator 100.

> x% = x / 100

So 25% = 25/100 = 1/4 = 0.25. These three forms (percent, fraction, decimal) are the same number.

## 3. The three basic question types

| Question | Formula | Example |
|---|---|---|
| What is x% of N? | N x x / 100 | 18% of 450 |
| A is what percent of B? | (A / B) x 100 | 45 is what % of 60? |
| A is x% of a number. Find the number. | A x 100 / x | 30% of a number is 63 |

**Worked:**
- 18% of 450: 10% = 45, 8% = 36 (1% is 4.5, times 8). Total = **81**.
- 45 is what % of 60: 45/60 = 3/4 = **75%**.
- 30% of a number = 63: number = 63 x 100 / 30 = **210**.

## 4. The base rule (the most important idea)

A percentage is always **a percentage of something**. That "something" is the **base**. Most mistakes come from using the wrong base.

Find the base from the words:
- "x% **of** N": the base is N.
- "A is x% **more than** B", "A is x% **less than** B": the base is **B** (the word after "than").
- "increase **from** 80 to 100": the base is the **original** (80).

## 5. Percentage change

> % change = (new - old) / old x 100

The base is always the **old (original)** value.

- Price rises 80 -> 100: change = 20/80 = **+25%**.
- Price falls 100 -> 80: change = 20/100 = **-20%**.

Same two numbers, different percentage, because the base changed.

## 6. Multiplying factors (the fastest method)

- Increase by x%: multiply by (1 + x/100). So +20% means x 1.2.
- Decrease by x%: multiply by (1 - x/100). So -20% means x 0.8.

**Successive changes:** multiply the factors.
- +10% then -10%: 1.1 x 0.9 = 0.99, so a **1% decrease**, not zero.
- +30% then -20%: 1.3 x 0.8 = 1.04, so **+4%**.
- Three changes: +10%, +20%, -10%: 1.1 x 1.2 x 0.9 = 1.188, so **+18.8%**.

**Shortcut formula for two changes (a% then b%):** net = a + b + (a x b)/100.
- +30 and -20: 30 - 20 + (30 x -20)/100 = 10 - 6 = **+4%** (matches).
- +20 and +20: 20 + 20 + 4 = **+44%**.

**Successive discounts** work the same way. Discounts of 20% and 10%: 0.8 x 0.9 = 0.72, so the net discount is **28%** (not 30%).

## 7. Reverse percentages (finding the original)

If a value after a change is known, divide by the factor.
- After a 20% discount, the price is Rs. 960. Original = 960 / 0.8 = **Rs. 1200**.
- After a 25% increase, a number is 150. Original = 150 / 1.25 = **120**.

## 8. The "more than / less than" shortcut (asked very often)

> If A is x% **more** than B, then B is less than A by **x / (100 + x) x 100 %**.
> If A is x% **less** than B, then B is more than A by **x / (100 - x) x 100 %**.

- A is 40% more than B -> B is less than A by 40/140 = **28.57%**.
- A is 20% less than B -> B is more than A by 20/80 = **25%**.

Easy way to remember: pick B = 100. Then A = 140 (or 80). Compare in the other direction using the new base.

## 9. Percentage of a percentage; spending problems

- 20% of 30% of 500 = 0.2 x 0.3 x 500 = **30**.
- Income Rs. 20,000. Rent 25%. Of the **remaining**, food 40%. Savings left?
  - Rent = 5,000, remaining 15,000.
  - Food = 40% of 15,000 = 6,000, remaining **9,000**, which is 45% of income.

## 10. Percentage points vs percent

Rising from 20% to 25% is **5 percentage points** but a **25% relative increase** (5/20). Exams like to test this wording.

## 11. Population and growth

Value after n years of r% growth = P x (1 + r/100)^n.
- 8,000 growing 25% a year for 2 years: 8000 x 1.25 x 1.25 = **12,500**.
(The same idea is used in compound interest, our next topics.)

## 12. A typical exam question: elections

A candidate gets 45% of the votes in a two-candidate election and loses by 400 votes. Total votes?
- The winner has 55%, so the difference is 55% - 45% = 10% of the total.
- 10% of total = 400, so total = **4,000**.

## 13. Mental-maths tricks

- 10%: move the decimal point one place left. 1%: two places.
- 5% = half of 10%. 15% = 10% + 5%. 20% = double 10%. 25% = a quarter.
- **x% of y = y% of x.** Example: 8% of 50 equals 50% of 8, which is 4. Always use the easier one.
- To add 10%: multiply by 1.1 (e.g., 240 + 24). To subtract 10%: multiply by 0.9.

## 14. Common mistakes

1. Dividing by the new value instead of the original.
2. Thinking +x% followed by -x% returns to the start.
3. Applying the second percentage to the original instead of the changed value.
4. Mixing up "percent" and "percentage points".
5. Forgetting "of the remaining" and using the original total.

## 15. Four-step method for any percentage question

1. **Find the base** (percent of what?).
2. **Choose a convenient number** for the base (100 or the LCM).
3. **Use factors** (1.2, 0.8...) instead of long arithmetic.
4. **Sanity check:** is the answer sensible (bigger or smaller than the starting value, as expected)?

## 16. Extra rules (so nothing is missed)

| Rule | Formula | Example |
|---|---|---|
| Up x%, then down x% | net change = -x^2 / 100 % | 10% -> -1%; 20% -> -4%; 30% -> -9% |
| Price rises x%, keep spending the same | cut consumption by x/(100+x) x 100 % | Price +50% -> cut by 33 1/3% |
| Price falls x%, keep spending the same | raise consumption by x/(100-x) x 100 % | Price -20% -> raise by 25% |
| Chain: A is x% of B, B is y% of C | A is (x x y)/100 % of C | A is 20% of B, B is 50% of C -> A is 10% of C |
| A is x% of B | A : B = x : 100 | A is 40% of B -> A : B = 2 : 5 |
| x% of A = y% of B | A : B = y : x | 15% of A = 25% of B -> A : B = 5 : 3 |
| Product changes (area = length x breadth) | a + b + ab/100 | Length +10%, breadth +10% -> +21% |
| Two groups (Venn) | Both = A + B - Union; Neither = 100 - Union | |
| Mixtures where one part stays fixed | new total = fixed quantity / new fraction | |
| Pass/fail marks | difference in % of max = difference in marks | |
